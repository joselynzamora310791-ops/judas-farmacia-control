# Judas Farmacia Control

Crea una aplicación web completa llamada FARMACIA SAN JUDAS SIG.

Es un sistema de información gerencial para una farmacia ubicada en Managua, Nicaragua

Quiero un diseño profesional, moderno y fácil de utilizar, con colores azul, blanco y verde.

La aplicación debe tener un menú lateral con los siguientes módulos:

1.       Dashboard

2.       Productos e inventario

3.       Categorías

4.       Clientes

5.       Ventas

6.       Reportes

7.       Análisis ABC de productos

8.       Usuarios y roles

En el inventario necesito registrar código, nombre del producto, categoría, precio, existencia, stock mínimo y fecha de vencimiento.

Mostrar alertas rojas para productos con stock bajo y alertas naranjas para productos que vencen en menos de 30 días.

El sistema tendrá dos roles: gerente y cajero.

El gerente tendrá acceso a todos los módulos.

El cajero podrá consultar productos y registrar ventas, pero no modificar precios, ni acceder al dashboard.

Utiliza Supabase como base de datos y prepara la aplicación para guardar información real.

Todos los textos deben estar en español y los precios expresados en córdobas nicaragüenses (C$)
